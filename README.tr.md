# SAGE Audit — Türkçe

SAGE bir sayfayı üç açıdan inceler: teknik SEO, varlık tabanlı AEO ve AI yanıtlarında citation hazırlığı için GEO.

```bash
pip install sage-audit
sage audit https://example.com
```

API anahtarı, LLM veya GPU gerekmez. Gelişmiş embedding isteğe bağlıdır; kurulmazsa araç deterministik yerel yönteme döner. Sonuç teknik bir teşhistir, sıralama veya citation garantisi değildir.
