# SAGE Audit — Azərbaycan dili

SAGE səhifəni üç istiqamətdə yoxlayır: texniki SEO, obyekt əsaslı AEO və süni intellekt cavablarında sitat hazırlığı üçün GEO.

```bash
pip install sage-audit
sage audit https://example.com
```

API açarı, LLM və ya GPU tələb olunmur. Qabaqcıl embedding istəyə bağlıdır; quraşdırılmadıqda alət deterministik lokal üsuldan istifadə edir. Nəticə texniki diaqnostikadır, sıralama və ya sitat zəmanəti deyil.
