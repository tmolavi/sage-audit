# Changelog

All notable changes to SAGE Audit are documented here.

## [v2026.1.1] - 2026-09-18
### Added
- Standardized runnable examples (`examples/example_audit.json`, `examples/audit_example.py`).
- Automated GitHub Actions CI workflow across Python 3.10, 3.11, 3.12.
- Issue and pull request contribution templates.
- Explicit ecosystem navigation links and data contracts.

## [v2026.1.0] - 2026-09-17
### Added
- 3-Pillar Audit Engine providing diagnostic signals (L1–L4) for MAVI.
- FastMCP server integration.
- Deterministic RAG chunking and Citation Survival Proxy (CSP).
- Spec-compliant `/llms.txt` generation.
