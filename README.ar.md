# SAGE Audit — العربية

يفحص SAGE الصفحة من ثلاث زوايا: تحسين محركات البحث التقني، وAEO الخاص بالكيانات، وGEO للاستعداد للاستشهاد في إجابات الذكاء الاصطناعي.

```bash
pip install sage-audit
sage audit https://example.com
```

لا يحتاج إلى مفتاح API أو LLM أو GPU. الـ embedding المتقدم اختياري؛ وإذا لم يكن مثبتاً يستخدم البرنامج طريقة محلية حتمية. النتيجة تشخيص فني وليست ضماناً للترتيب أو الاستشهاد.
