# SAGE Audit — راهنمای فارسی

SAGE یک صفحه را از سه زاویه بررسی می‌کند: SEO فنی، AEO موجودیت و GEO برای آمادگی citation در موتورهای پاسخ.

```bash
pip install sage-audit
sage audit https://example.com
```

کلید API، LLM و GPU لازم نیست. embedding پیشرفته اختیاری است و در صورت نصب نبودن، ابزار از روش قطعی داخلی استفاده می‌کند. نتیجه تشخیص فنی همان صفحه است، نه تضمین رتبه یا citation آینده.
